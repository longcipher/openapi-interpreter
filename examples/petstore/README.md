# Petstore Examples

Classic Petstore spec used to validate Interpreter Mode commands.

- `petstore.yaml` — Petstore v3 OpenAPI spec (YAML format)
- `petstore.json` — Same spec in JSON format (converted via jaq)
- `example-session.md` — Full example conversation showing the agent navigating Petstore
- `l0-output.json` — Reference output from Level 0 jaq command
- `l1-output.json` — Reference output from Level 1 jaq command
- `l2-output.json` — Reference output from Level 2 jaq command (pets resource)
- `l3-output.json` — Reference output from Level 3 jaq command (GET /pets/{petId})
- `l4-output.json` — Reference output from Level 4 jaq command (Pet schema)
