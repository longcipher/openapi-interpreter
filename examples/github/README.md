# GitHub REST API Examples

A filtered subset of the GitHub REST API spec (repos, issues, pulls, search tags).

- `github-subset.yaml` — Filtered GitHub API spec (unresolved $refs)
- `github-subset-bundled.yaml` — Bundled spec (all $refs resolved, generated via swagger-cli)
- `example-session.md` — Full example: GET /repos/{owner}/{repo}/issues via Interpreter Mode
- `generator-mode-session.md` — Full example: same endpoint via Generator Mode
